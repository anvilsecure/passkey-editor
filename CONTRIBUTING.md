# Contributing to Passkey Editor

Thank you for considering contributing to Passkey Editor!

There are many ways to contribute to the project and all are appreciated:

- **Ideas**: if there is an idea you have for a new feature or improvement then you can
  [create an issue](../../issues/new?template=feature_request.md).
- **Bug Reports**: if you have found a bug then please
  [raise an issue](../../issues/new?template=bug_report.md).
- **Documentation**: the documentation can always do with improvement! This can be done by
  raising a [pull request](../../pulls) with the relevant changes.
- **Code**: pull requests with code changes are welcome. For any substantial changes, it is
  probably best to discuss the plans before expending too much effort.

Please also note our [code of conduct](CODE_OF_CONDUCT.md).
